HOW TO RUN THE APPLICATION:

## Quick Start

1. Open a terminal/command prompt
2. Navigate to the project directory:
   ```bash
   cd /path/to/COS426_FinalProject
   ```
3. Start a local web server:
   
   ```bash
   python3 -m http.server 8000
   ```
   ```
4. Open your web browser and navigate to:
   - **Interactive Mode (Main Editor):** http://localhost:8000/index.html
   - **Batch Mode:** http://localhost:8000/batch.html
   - **Flow Vectors Creator:** http://localhost:8000/morphLines.html
