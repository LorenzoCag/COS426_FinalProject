## Quick Start

1. Open terminal
2. Navigate to project directory:

   ```bash

   cd /path/to/COS426_FinalProject

   ```

3. Start local web server:

   ```bash
   
   python3 -m http.server
   
   ```

4. Open web browser and navigate to:
   - [Interactive Mode (Main Editor)](http://localhost:8000/index.html)
   - [Batch Mode](http://localhost:8000/batch.html)
   - [Flow-Vector Creator](http://localhost:8000/morphLines.html)
